# Privacy

This version has no sign-in, analytics, advertising, telemetry, database, or billing integration.
Student records live in memory while the app is open. The app reads only files you select,
and saves JSON/PDF using your device's file or download controls. It does not upload records.

The web host can receive standard asset request logs, including IP addresses. App assets
are distinct from student data. Files saved in a cloud-synced folder may be uploaded by
that folder's sync software; the app cannot control that. OS share/print destinations
and browser extensions are also outside the app's control.

Files are not encrypted by the app. Keep them on a trusted device and share only intended
copies. A PDF contains the student's name, birth date, optional contact details, courses,
awards, and activities. Check it before sharing. JSON includes all students and their fields.

There is no account recovery or operator backup. Keep your own backups. Closing the app
can lose unsaved changes. Deleting a student in a session does not alter previously saved
files; save a new file and manage older copies yourself.
